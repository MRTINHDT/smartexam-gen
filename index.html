Khóa AI Google Gemini API

💡 **Làm thế nào để lấy khóa API miễn phí?**
1. Học sinh/phụ huynh truy cập cổng **[Google AI Studio](https://aistudio.google.com/)**.
2. Đăng nhập bằng tài khoản Gmail thông thường.
3. Bấm nút **"Get API Key"** -> Tạo khóa mới (Create API Key) rồi sao chép dán vào đây.
*Mọi cuộc gọi AI đều chạy trực tiếp từ trình duyệt của con, khóa được lưu an toàn cục bộ.*
